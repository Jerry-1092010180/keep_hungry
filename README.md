# 🎓 Campus Tech Forum (基于 GitHub Discussions 的大学生技术社区)

欢迎来到本仓库！👋
这里不仅仅是一个代码仓库，更是一个**面向大学生的开放技术交流社区**。我们依托 GitHub 自带的 **Discussions** 功能，打造一个类似“校园论坛”的空间，让大家可以自由讨论、分享、学习和连接彼此。

---

## 🌟 项目愿景

我们希望构建一个：

* 💬 **自由讨论的技术社区**：涵盖编程、AI、系统、硬件、竞赛等各类话题
* 📚 **知识沉淀的平台**：让优质讨论和经验长期可查
* 🤝 **连接志同道合的人**：找到队友、朋友甚至未来的合作伙伴
* 🚀 **低成本可持续运行**：无需服务器、无需维护博客，完全基于 GitHub 生态

---

## 🧩 你可以在这里做什么？

### 1️⃣ 技术讨论

* 提问 / 解答问题（类似 Stack Overflow）
* 分享学习心得、踩坑经验
* 探讨前沿技术（如大模型、分布式系统等）

### 2️⃣ 分享代码 & 项目

* 上传有趣的小项目 💡
* 展示课程作业 / 实验成果
* 分享工具、脚本、自动化方案

### 3️⃣ 资源交流

* 推荐书籍 / 教程 / 课程
* 分享学习路线
* 整理优质资料合集

### 4️⃣ 社交 & 组队

* 寻找比赛队友 🏆
* 发起项目合作
* 结交技术伙伴

## 🏗️ Discussions 使用指南

进入仓库顶部的 **Discussions** 页面，你可以看到不同分类：

| 分类               | 用途       |
| ---------------- | -------- |
| 💡 Ideas         | 新想法 / 创意 |
| 🙋 Q&A           | 提问与解答    |
| 📢 Show and Tell | 项目展示     |
| 📚 Resources     | 学习资源     |
| 🧑‍🤝‍🧑 General | 自由讨论     |

👉 建议发帖时选择合适分类，方便大家查找和参与。

---

## 📌 社区规则（请务必遵守）

为了维护良好的社区环境，请大家：

* ✅ 尊重他人，理性讨论
* ✅ 尽量提供有价值的信息（代码、思路、资料）
* ✅ 提问前先简单搜索，避免重复问题
* ❌ 不发布广告 / 无关内容
* ❌ 不进行人身攻击或恶意行为

---

## 💡 为什么选择 GitHub Discussions？

相比传统论坛或个人博客：

| 方式                 | 优势           |
| ------------------ | ------------ |
| GitHub Discussions | ✅ 免费、稳定、无需维护 |
| 自建论坛               | ❌ 需要服务器和运维   |
| 个人博客               | ❌ 互动性较弱      |

同时你还可以：

* ⭐ 直接关联代码仓库
* 🔔 收到通知，不错过回复
* 🧑‍💻 使用 GitHub 账号即可参与

---

## 🚀 如何开始？

1. 点开仓库的 **Discussions**
2. 点击 **New Discussion**
3. 选择分类并发布你的内容 🎉
